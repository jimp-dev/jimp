Jimp draws text with bitmap fonts: each character is a small picture, copied onto your image wherever the text needs it.
There's no font rendering engine to install, and the result looks the same everywhere, but a font has a fixed size, a fixed color and only the characters it was made with.

## Load a font and print

Load a font with [`loadFont`](/jimp/methods/load-font/), then draw with [`print`](/jimp/methods/print/).
The fonts that come with Jimp are named exports of `jimp/fonts`:

```ts title="example.ts"
import { Jimp, loadFont } from "jimp";
import { SANS_32_BLACK } from "jimp/fonts";

const image = new Jimp({ width: 400, height: 120, color: 0xffffffff });
const font = await loadFont(SANS_32_BLACK);

image.print({ font, x: 10, y: 10, text: "Hello, world" });

await image.write("hello.png");
```

`loadFont` is asynchronous because it reads the font file and its image pages. Load each font once and reuse it for every image and every `print` call.

## The bundled fonts

Jimp includes Open Sans in these sizes. The number is the font size in pixels; the line height is a little larger.

| Size  | Black            | White            | Characters                       |
| ----- | ---------------- | ---------------- | -------------------------------- |
| 8px   | `SANS_8_BLACK`   | `SANS_8_WHITE`   | ASCII, Latin-1 and `€`           |
| 10px  | `SANS_10_BLACK`  |                  | ASCII                            |
| 12px  | `SANS_12_BLACK`  |                  | ASCII                            |
| 14px  | `SANS_14_BLACK`  |                  | ASCII                            |
| 16px  | `SANS_16_BLACK`  | `SANS_16_WHITE`  | ASCII, Latin-1 and `€`           |
| 32px  | `SANS_32_BLACK`  | `SANS_32_WHITE`  | ASCII, Latin-1 and `€`           |
| 64px  | `SANS_64_BLACK`  | `SANS_64_WHITE`  | ASCII, Latin-1 and `€`           |
| 128px | `SANS_128_BLACK` | `SANS_128_WHITE` | ASCII, Latin-1 and `€`           |

"Latin-1" covers accented letters such as `é`, `ñ` and `ü`, and symbols such as `£`, `©` and `°`. The Latin-1 fonts don't have a glyph for the backtick (`` ` ``).

### Fonts in the browser

The `jimp/fonts` constants are absolute paths into the installed package on disk, built with Node's `path` and `url` modules.
They can't be used in the browser, from a CDN or in a browser bundle.

Instead, serve the `.fnt` file and its `.png` pages from your site, and pass the URL to `loadFont`:

```ts title="main.ts"
import { Jimp, loadFont } from "jimp";

const font = await loadFont("/fonts/open-sans-32-black/open-sans-32-black.fnt");
```

The bundled fonts are in the `dist/fonts/open-sans/` folder of the `@jimp/plugin-print` package, under the Apache License 2.0.
This site does exactly that for the playground below. See also [Using in Browser](/jimp/guides/browser/#fonts).

## Wrapping and alignment

Give `print` a `maxWidth` and it wraps the text at spaces so that no line is wider.
`\n` in the text always starts a new line.

To align the text, pass an object as `text` with `alignmentX` from `HorizontalAlign` and `alignmentY` from `VerticalAlign`.
The text is aligned inside the box that starts at `x`, `y` and is `maxWidth` wide and `maxHeight` tall.

```ts title="example.ts"
import { Jimp, loadFont, HorizontalAlign, VerticalAlign } from "jimp";
import { SANS_32_WHITE } from "jimp/fonts";

const image = await Jimp.read("photo.jpg");
const font = await loadFont(SANS_32_WHITE);

// A caption centered at the bottom, with a 20px margin
image.print({
  font,
  x: 20,
  y: 20,
  text: {
    text: "Summer 2026",
    alignmentX: HorizontalAlign.CENTER,
    alignmentY: VerticalAlign.BOTTOM,
  },
  maxWidth: image.width - 40,
  maxHeight: image.height - 40,
});
```

| Constant                   | Aligns text                          | Needs       |
| -------------------------- | ------------------------------------ | ----------- |
| `HorizontalAlign.LEFT`     | to the left edge of the box (default) |             |
| `HorizontalAlign.CENTER`   | centered in the box                  | `maxWidth`  |
| `HorizontalAlign.RIGHT`    | to the right edge of the box         | `maxWidth`  |
| `VerticalAlign.TOP`        | to the top of the box (default)      |             |
| `VerticalAlign.MIDDLE`     | centered vertically                  | `maxHeight` |
| `VerticalAlign.BOTTOM`     | to the bottom of the box             | `maxHeight` |

<Aside type="caution">
  Always set `maxWidth` when you use `CENTER` or `RIGHT`. Without it, the box is
  infinitely wide and `print` throws a validation error. Without `maxHeight`,
  `MIDDLE` and `BOTTOM` have no effect.
</Aside>

`maxHeight` positions the text but doesn't cut it off: lines that don't fit continue below the box.

## Measuring text

[`measureText`](/jimp/methods/measure-text/) returns the width of one line, and [`measureTextHeight`](/jimp/methods/measure-text-height/) returns the height of text wrapped at a given width.
Both use the same spacing and line breaking as `print`, so you can size things before drawing:

```ts title="example.ts"
import { Jimp, loadFont, measureText, measureTextHeight } from "jimp";
import { SANS_32_BLACK } from "jimp/fonts";

const font = await loadFont(SANS_32_BLACK);
const text = "Sale";

// A badge that fits the text with 10px of padding on each side
const badge = new Jimp({
  width: measureText(font, text) + 20,
  height: measureTextHeight(font, text, Infinity) + 20,
  color: 0xffd83aff,
});

badge.print({ font, x: 10, y: 10, text });
```

`print`'s `cb` option also reports where the text ended, which helps when you stack paragraphs. See [`print`](/jimp/methods/print/#find-where-the-text-ended).

## Coloring text

A glyph is copied from the font's image as it is, so the text color is part of the font.
To print in another color, print a white font onto a transparent layer, change the color of the layer's pixels while keeping their alpha, and [`composite`](/jimp/methods/composite/) the layer onto the image:

```ts title="example.ts"
import { Jimp, loadFont, measureText, measureTextHeight } from "jimp";
import { SANS_64_WHITE } from "jimp/fonts";

const image = new Jimp({ width: 400, height: 120, color: 0xffffffff });
const font = await loadFont(SANS_64_WHITE);
const text = "Jimp";

const layer = new Jimp({
  width: measureText(font, text),
  height: measureTextHeight(font, text, Infinity),
  color: 0x00000000,
});
layer.print({ font, x: 0, y: 0, text });

// Keep each pixel's alpha, replace its color with #ff4b4b
layer.scan((x, y, idx) => {
  layer.bitmap.data[idx] = 0xff;
  layer.bitmap.data[idx + 1] = 0x4b;
  layer.bitmap.data[idx + 2] = 0x4b;
});

image.composite(layer, 20, 20);
```

The layer is also a good place for effects: blur a dark copy of it for a drop shadow, or rotate it before compositing.
If you always need the same color, it's simpler to generate a font in that color (see below).

## Characters a font doesn't have

`print` draws `?` for any character the font has no glyph for, and leaves whitespace without a glyph blank.
So if Chinese, Japanese, Korean, Cyrillic or emoji text prints as `???`, the font doesn't include those characters.
The only fix is a font that does.

## Making your own fonts

Fonts are in the [BMFont](https://www.angelcode.com/products/bmfont/) format: a `.fnt` file that describes each glyph, and one or more `.png` pages that hold the glyph images.
Text, XML, JSON and binary `.fnt` files all work.

Any BMFont generator can make one from a TrueType or OpenType font. For example, with [fontbm](https://github.com/vladimirgamalyan/fontbm) and [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP):

```sh
# chars.txt holds the characters to include, e.g. こんにちは世界
fontbm --font-file NotoSansJP-Regular.ttf --output noto-sans-jp \
  --font-size 32 --chars 32-126 --chars-file chars.txt --color 0,0,0
```

Then load the `.fnt` file, with its `.png` pages in the same directory:

```ts title="example.ts"
const font = await loadFont("fonts/noto-sans-jp.fnt");

image.print({ font, x: 10, y: 10, text: "こんにちは世界" });
```

- **Set the color and size when generating.** Jimp doesn't scale or tint glyphs.
- **Use plain bitmaps.** Signed distance field (SDF or MSDF) fonts are meant to be rendered by a shader and won't look right.
- **Include only what you need.** CJK fonts have thousands of glyphs; limiting the characters keeps the pages small.
- **Characters outside the Basic Multilingual Plane** such as emoji work too, as long as the font has glyphs for them.
- **Check the license** of the font you convert. Many fonts allow embedding; some don't.
