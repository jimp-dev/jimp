Jimp (JavaScript Image Manipulation Program) is a package that makes it easy to load and manipulate images in the browser and Node.js.
It aims to run anywhere that JavaScript is supported.

[Read the full documentation](/jimp/api/jimp/classes/jimp/) to learn more about the API.

```bash
pnpm add jimp
```

Jimp supports the following image formats:

- [bmp](https://en.wikipedia.org/wiki/BMP_file_format)
- [gif](https://en.wikipedia.org/wiki/GIF)
- [ico](<https://en.wikipedia.org/wiki/ICO_(file_format)>) (and reading cur)
- [jpeg](https://en.wikipedia.org/wiki/JPEG)
- [png](https://en.wikipedia.org/wiki/Portable_Network_Graphics)
- [tiff](https://en.wikipedia.org/wiki/TIFF)

<Aside type="caution" title="Watch out!">
  Jimp is built on JavaScript implementations of image formats. These
  implementations are not optimized for performance and may allocate a lot of
  memory before using.
</Aside>

By default JPEG, GIF, TIFF and BMP images larger than 100 megapixels are rejected.
See [Reading Large Images](/jimp/guides/reading-large-images/) to raise the limits.

## Usage

The workflow for using jimp

<Steps>

1. Load an image.

   ```ts
   import { Jimp } from "jimp";

   const image = await Jimp.read("test/image.png");
   ```

2. Manipulate the image.

   ```ts
   image.resize({ w: 100 });
   ```

3. Save the image.

   ```ts
   await image.write("test/output.png");
   ```

</Steps>

Methods like `resize` only change the image in memory.
Nothing is saved until you call `write` or `getBuffer`.

## Creating an image

v1 has no callbacks.
Every way to create an image either returns the image or a promise you `await`.

`Jimp.read` loads an image from a file path or a URL:

```ts
const image = await Jimp.read("test/image.png");
```

If you already have the encoded image in memory, use `Jimp.fromBuffer`:

```ts
import { readFile } from "node:fs/promises";

const image = await Jimp.fromBuffer(await readFile("test/image.png"));
```

To start from a blank image, pass a width and height to the constructor.
It's synchronous.
`color` is optional and defaults to transparent (`0x00000000`):

```ts
const image = new Jimp({ width: 256, height: 256, color: 0xffffffff });
```

If you're upgrading from v0, see the [migration guide](/jimp/guides/migrate-to-v1/).

## Saving an image

`write` encodes the image and saves it to a file.
The file extension picks the format:

```ts
await image.write("test/output.jpg");
```

`getBuffer` encodes the image in memory instead, for example to send it in an HTTP response:

```ts
import { JimpMime } from "jimp";

const buffer = await image.getBuffer(JimpMime.png);
```

`write` needs a file system, so in the browser use `getBuffer` or `getBase64`.
See [Using in Browser](/jimp/guides/browser/).
