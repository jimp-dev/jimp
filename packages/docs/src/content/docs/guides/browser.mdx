## Usage

There are a few main ways to use Jimp in the browser.
### From a CDN

The browser build at `dist/browser/index.js` is a self-contained ES module, so you can import it straight from a CDN without a bundler.

```html
<script type="module">
  import { Jimp } from "https://cdn.jsdelivr.net/npm/jimp@1/dist/browser/index.js";

  const image = await Jimp.read("/some/url");

  image.greyscale();

  document.querySelector("img").src = await image.getBase64("image/png");
</script>
```

The same file is on unpkg at `https://unpkg.com/jimp@1/dist/browser/index.js`.
`jimp@1` always loads the latest v1 release. Pin an exact version such as `jimp@1.7.0` to make sure an update never changes your page.

The `jimp/fonts` export isn't self-contained, so it can't be imported from a CDN.
Load your fonts by URL with `loadFont` instead (see [Using Fonts](#using-fonts)).


### With hosted file

You can initialize a Jimp instance from a URL or a file path.

```ts
import { Jimp } from "jimp";

// Read a file hosted on the same domain
const image1 = await Jimp.read("/some/url");

// Read a file hosted on a different domain
const image2 = await Jimp.read("https://some.other.domain/some/url");
```

### With uploaded files

Or you can use Jimp with an `ArrayBuffer`.
Here we take a user's uploaded image and modify it to greyscale.

```ts
function handleFile(e: React.ChangeEvent<HTMLInputElement>) {
  const reader = new FileReader();

  reader.onload = async (e) => {
    const image = await Jimp.fromBuffer(e.target?.result);

    image.greyscale();

    const base64 = await image.getBase64("image/jpeg");
  };

  reader.readAsArrayBuffer(e.target.files[0]);
}

input.addEventListener("change", handleFile);
```

### Using Canvas

You can also use Jimp with a canvas.
`Jimp.fromBitmap` takes the `ImageData` from `getImageData` directly.

```ts
import { Jimp } from "jimp";

const canvas = document.getElementById("my-canvas");
const ctx = canvas.getContext("2d");

// Load the canvas into a Jimp instance
const image = Jimp.fromBitmap(
  ctx.getImageData(0, 0, canvas.width, canvas.height)
);

// Manipulate the image
image.greyscale().resize({ w: 100 });

// Make an ImageData from the image's pixels
const imageData = new ImageData(
  new Uint8ClampedArray(image.bitmap.data),
  image.bitmap.width,
  image.bitmap.height
);

// Write back to the canvas
canvas.width = image.bitmap.width;
canvas.height = image.bitmap.height;
ctx.putImageData(imageData, 0, 0);
```

#### Raw pixel data

`Jimp.fromBitmap` and `new Jimp({ data, width, height })` accept any raw RGBA pixel data with 4 bytes per pixel:

- an `ImageData`
- a `Uint8ClampedArray`, such as `imageData.data`
- a `Uint8Array` or a `Buffer`, including a view into part of a larger `ArrayBuffer`
- an array of `0xRRGGBBAA` numbers

`data` must hold exactly `width * height * 4` bytes. Otherwise Jimp throws an error.

Jimp always stores pixels in a `Buffer` (`image.bitmap.data`).
A `Uint8ClampedArray` or `Uint8Array` is copied into a new `Buffer`, so editing the image never changes your `ImageData`, and the reverse.
`Jimp.fromBitmap` copies a `Buffer` too, while the constructor uses a `Buffer` without copying it.

To skip the copy when writing back to a canvas, make a view over the image's memory instead.
Pass the offset and length, because a `Buffer` can be a slice of a larger `ArrayBuffer`:

```ts
const { data, width, height } = image.bitmap;
const imageData = new ImageData(
  new Uint8ClampedArray(data.buffer, data.byteOffset, data.length),
  width,
  height
);
```

That `ImageData` shares memory with the image until a method like `resize` or `crop` replaces `image.bitmap`, so put it on the canvas straight away.

## Using Fonts

Jimp supports loading fonts from a URL or a file path.
You must host the fonts and will not be able to use the ones included in the node version of Jimp.

## Web Workers

Jimp can be slow and you don't want that running on the main thread.
Workers can make this experience a lot better.

First define a worker.
This is where you should import jimp and do your image transformations.

```ts
import { Jimp, loadFont } from "jimp";

// eslint-disable-next-line @typescript-eslint/no-explicit-any
const ctx: Worker = self as any;

ctx.addEventListener("message", async (e) => {
  // Initialize Jimp
  const image = await Jimp.fromBuffer(e.data.image);
  const options = e.data.options;

  // Manipulate the image
  if (options.blur) {
    image.blur(options.blur);
  }

  // Return the result
  ctx.postMessage({ base64: await image.getBase64("image/png") });
});
```

Then you can use the worker.

```ts
const fileData: ArrayBuffer = new ArrayBuffer(); // Your image data
const worker = new Worker(new URL("./jimp.worker.ts", import.meta.url), {
  type: "module",
});

worker.postMessage({
  image: fileData,
  options: {
    blur: 8
  },
});

worker.addEventListener("message", (e) => {
  setOutput(e.data.base64);
  setIsLoading(false);
});
```
