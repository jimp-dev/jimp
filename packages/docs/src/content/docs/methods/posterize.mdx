`posterize` limits each color channel to `n` evenly spaced levels, replacing smooth gradients with flat bands of color like a screen-printed poster.

## Signature

```ts title="posterize.d.ts"
image.posterize(n: number): this
```

`posterize` changes the image in place and returns it, so you can chain more calls after it.

## Parameters

| Parameter | Type     | Default  | Description                                                                      |
| --------- | -------- | -------- | -------------------------------------------------------------------------------- |
| `n`       | `number` | required | The number of levels per channel. Values below `2` are treated as `2`.           |

## Example

```ts title="example.ts"
import { Jimp } from "jimp";

const image = await Jimp.read("photo.jpg");

image.posterize(5);

await image.write("photo-poster.jpg");
```

### A bold graphic look

Very few levels give strong, flat shapes. Raising the saturation first makes the colors pop:

```ts title="example.ts"
image.color([{ apply: "saturate", params: [40] }]).posterize(3);
```

## Notes

- **Levels per channel, not colors.** Each of red, green and blue gets `n` levels, so the image can have up to `n³` colors: `n = 4` allows 64. To choose the exact number of colors, use [`quantize`](/jimp/methods/quantize/).
- **The levels.** With `n` levels the values are `0`, `255 / (n − 1)`, `2 × 255 / (n − 1)` … `255`. For `n = 4` that's `0`, `85`, `170` and `255`.
- **Alpha is unchanged.**
- **Errors.** An `n` that isn't a number throws `n must be numbers`. Fractional values don't throw; they produce uneven levels, so use whole numbers.

<Aside type="caution" title="Values round down">
  Each channel is rounded down to the level below it, and only `255` itself
  reaches the top level. With few levels the image gets noticeably darker: at
  `n = 2` every channel below `255` becomes `0`. Brighten the image first, for
  example with `brightness(1.2)`, if the result looks too dark.
</Aside>
