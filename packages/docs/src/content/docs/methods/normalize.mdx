`normalize` stretches the levels of a dull or hazy image so that its darkest value becomes `0` and its brightest becomes `255`.
It works on each channel separately, so it can also correct a slight color cast.

## Signature

```ts title="normalize.d.ts"
image.normalize(): this
```

`normalize` takes no arguments. It changes the image in place and returns it, so you can chain more calls after it.

## Example

```ts title="example.ts"
import { Jimp } from "jimp";

const image = await Jimp.read("scan.jpg");

image.normalize();

await image.write("scan-normalized.jpg");
```

### Clean up a grayscale scan

For documents, remove the color first so the three channels stretch together:

```ts title="example.ts"
image.greyscale().normalize();
```

## Notes

- **How it's computed.** For each channel, `normalize` finds the lowest value `min` and the highest value `max` used anywhere in the image, then maps each value `c` to `(c − min) × 255 / (max − min)`.
- **Per channel.** Red, green and blue are stretched independently, which can shift the colors. If you want only the brightness stretched, call [`greyscale`](/jimp/methods/greyscale/) first or use [`contrast`](/jimp/methods/contrast/).
- **Outliers limit the effect.** A single pure black and a single pure white pixel are enough to make `normalize` do nothing. There's no option to ignore a percentage of extreme pixels.
- **Transparent pixels count.** The color stored in fully transparent pixels is included when finding `min` and `max`. Alpha itself is unchanged.

<Aside type="caution" title="Single-value channels turn black">
  If a channel has the same value in every pixel, `max − min` is `0` and the
  channel is set to `0` everywhere. A solid-color image becomes black, and an
  image whose blue channel is `128` in every pixel loses its blue entirely.
  Watch for this with generated images and flat graphics.
</Aside>
