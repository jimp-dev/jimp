`render` takes a tree of boxes, text and images, lays it out in rows and columns like CSS flexbox, and draws it on a new image.
Use it for Open Graph cards, social banners, badges and anything else where text has to wrap and things have to line up.
The [Open Graph images guide](/jimp/guides/og-images/) builds a card step by step.

`render` comes from `@jimp/layout`, which isn't part of `jimp`:

<InstallCommand pkg="@jimp/layout" />

## Signature

```ts title="render.d.ts"
import { layout, render } from "@jimp/layout";

render<I>(
  tree: LayoutNode,
  options: {
    Jimp: JimpConstructor<I>;
    width?: number;
    height?: number;
    background?: Fill;
  },
): Promise<I>

layout(
  tree: LayoutNode,
  options?: { width?: number; height?: number; Jimp?: { read } },
): Promise<ComputedLayout>
```

`render` returns a promise of a new image, made with the `Jimp` class you pass. `layout` works out the same positions without drawing anything.
The node, prop and option types are exported from `@jimp/layout`.

## Options

| Option       | Type                    | Default             | Description                                                                                                                                       |
| ------------ | ----------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Jimp`       | Jimp class              | required            | The class to make the image with: `Jimp` from `jimp`, or one from [`createJimp`](/jimp/guides/custom-jimp/). Its `read` reads image nodes whose `src` is a path, URL or buffer. |
| `width`      | `number`                | the tree's width    | The width of the image, a whole number of pixels.                                                                                                |
| `height`     | `number`                | the tree's height   | The height of the image, a whole number of pixels.                                                                                               |
| `background` | `Fill`                  | transparent         | A color or gradient to fill the image with before drawing the tree.                                                                              |

The root of the tree fills the image, less its margin, unless it has its own `width` or `height`. Give the root `width: "auto"` or `height: "auto"` to size it to its content instead.
Without a `width` or `height` option, the image is the size of the tree in that direction.

## Nodes

A tree is made of three kinds of node, told apart by `type`. Each is a plain object:

```ts title="tree.ts"
const tree = {
  type: "box",
  direction: "row",
  gap: 16,
  children: [
    { type: "image", src: logo, width: 48, height: 48 },
    { type: "text", text: "Hello", font, fontSize: 32 },
  ],
};
```

- **`box`**: a row or column of other nodes, in `children`.
- **`text`**: the string in `text`, wrapped to fit its box.
- **`image`**: the image in `src`, a Jimp image or anything `Jimp.read` reads.

Every node takes the [layout props](#layout-props) and the [style props](#style-props). Boxes also take the [box props](#box-props), and boxes and text take the [text props](#text-props).

### Layout props

| Prop                         | Type        | Default      | Description                                                                                                                  |
| ---------------------------- | ----------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `width`, `height`            | `Size`      | `"auto"`     | The size, border and padding included. `"auto"` sizes the node to its content, or stretches it.                             |
| `minWidth`, `maxWidth`       | `Length`    | none         | Limits on the width. A min beats a max.                                                                                      |
| `minHeight`, `maxHeight`     | `Length`    | none         | Limits on the height.                                                                                                        |
| `padding`                    | `Spacing`   | `0`          | Space inside the border, around the content.                                                                                 |
| `margin`                     | `Spacing`   | `0`          | Space outside the border, around the node. Can be negative.                                                                  |
| `grow`                       | `number`    | `0`          | How much of the parent's spare space along its direction the node takes, relative to its siblings.                          |
| `shrink`                     | `number`    | `1`, `0` for images | How much the node shrinks when its parent is too small, relative to its siblings and its size. `0` keeps its size. |
| `alignSelf`                  | `Align`     | parent's     | Where the node goes across its parent's direction, instead of the parent's `align`.                                         |
| `position`                   | `string`    | `"relative"` | `"absolute"` takes the node out of the row or column and places it with `top`, `right`, `bottom` and `left`.                |
| `top`, `right`, `bottom`, `left` | `Length` | none        | For `position: "absolute"`: how far the node is from each edge of the parent's padding box.                                  |

- A `Size` is a number of pixels, a percentage of the parent's content box such as `"50%"`, or `"auto"`.
- A `Length` is a number of pixels or a percentage.
- A `Spacing` is one number for every side, `[vertical, horizontal]`, or `[top, right, bottom, left]`, like CSS.
- An `Align` is `"start"`, `"center"`, `"end"` or `"stretch"`.

An absolutely positioned node with `left` and `right` and no `width` stretches between them, and the same goes for `top`, `bottom` and `height`.

### Style props

| Prop          | Type                  | Default      | Description                                                                                                                      |
| ------------- | --------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `background`  | `Fill`                | none         | A color or gradient to fill the box with, under the border.                                                                      |
| `borderWidth` | `number`              | `0`          | The width of the border. It's inside the box, like CSS with `box-sizing: border-box`.                                           |
| `borderColor` | `Color`               | black        | The color of the border.                                                                                                         |
| `radius`      | `number \| object`    | `0`          | The corner radius: one number, or `{ topLeft, topRight, bottomRight, bottomLeft }`. Radii too big for the box are scaled down, so `999` makes a pill. |
| `shadow`      | `Shadow \| Shadow[]`  | none         | Shadows under the box, like CSS `box-shadow`. The first one is drawn on top.                                                     |
| `opacity`     | `number`              | `1`          | The opacity of the node and everything in it, from `0` to `1`.                                                                   |

A `Color` is a hex number (`0xRRGGBBAA`) or a CSS color string. A `Fill` is a color or a gradient sized to the box it fills:

- `{ type: "linear", angle?, stops }`: like CSS `linear-gradient`. `angle` is in degrees: `0` goes up, `90` right, and `180`, the default, down.
- `{ type: "radial", stops }`: a circle from the center out to the farthest corner, like CSS `radial-gradient(circle, ...)`.

`stops` is a list of colors, spread out evenly, or of `{ offset, color }` with offsets from `0` to `1`.

A `Shadow` takes the options of [`boxShadow`](/jimp/methods/box-shadow/), with the same defaults: `x` (`0`), `y` (`4`), `blur` (`12`), `spread` (`0`) and `color` (50% black). It follows the box's `radius`.

### Box props

| Prop        | Type                                                                                          | Default      | Description                                                    |
| ----------- | --------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------- |
| `children`  | `LayoutNode[]`                                                                                | `[]`         | The nodes in the box.                                          |
| `direction` | `"column" \| "row"`                                                                           | `"column"`   | Whether children are laid out top to bottom or left to right.  |
| `gap`       | `number`                                                                                      | `0`          | The space between children.                                    |
| `justify`   | `"start" \| "center" \| "end" \| "space-between" \| "space-around" \| "space-evenly"`         | `"start"`    | Where children go along the direction, like `justify-content`. |
| `align`     | `Align`                                                                                       | `"stretch"`  | Where children go across the direction, like `align-items`. `"stretch"` makes children without a size as wide as a column, or as tall as a row. |
| `overflow`  | `"visible" \| "hidden"`                                                                       | `"visible"`  | `"hidden"` clips the children to inside the border, rounded corners included. |

### Text props

Set text props on a box and the text inside it inherits them, the way CSS inherits `font` and `color`. A text node's own props win.

| Prop            | Type                              | Default                 | Description                                                                                               |
| --------------- | --------------------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------- |
| `text`          | `string`                          | required                | Text nodes only: the text. `\n` starts a new line.                                                       |
| `font`          | font                              | required                | A font from [`loadTTF`](/jimp/methods/load-ttf/), or a bitmap font from [`loadFont`](/jimp/methods/load-font/). |
| `fontSize`      | `number`                          | required for `loadTTF`  | The font size in pixels.                                                                                  |
| `color`         | `Fill`                            | black                   | What to fill the text with: a color, or a gradient sized to the text's box.                              |
| `lineHeight`    | `number`                          | the font's              | The height of each line in pixels.                                                                       |
| `letterSpacing` | `number`                          | `0`                     | Extra space between characters, in pixels.                                                              |
| `textAlign`     | `"left" \| "center" \| "right"`   | `"left"`                | How lines are aligned in the text's box.                                                                |
| `maxLines`      | `number`                          | none                    | Text nodes only: the most lines to show. Longer text is cut short with an ellipsis (`…`, or `...` if the font has no `…`). |

`fontSize`, `color`, `lineHeight` and `letterSpacing` only work with `loadTTF` fonts: bitmap fonts are drawn at the size and in the color they were made with.

### Image props

| Prop  | Type                                     | Default    | Description                                                                                                                       |
| ----- | ---------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `src` | Jimp image, `string`, `ArrayBuffer`, `Uint8Array` | required | The image, or a path, URL or buffer to read with the `Jimp` class's `read`. The image itself isn't changed.                |
| `fit` | `"fill" \| "cover" \| "contain"`         | `"fill"`   | How the image fills its box, like CSS `object-fit`: stretched, cropped to fill it with [`cover`](/jimp/methods/cover/), or fitted inside it with [`contain`](/jimp/methods/contain/). |

Without a `width` or `height` an image is its natural size. With only one of them, the other keeps the image's aspect ratio. An image with a `radius` is clipped to its rounded corners.
Images don't shrink when a row or column is too small, so they aren't squashed; give them `shrink: 1` to let them.

## Example

```ts title="badge.ts"
import { Jimp } from "jimp";
import { loadTTF } from "jimp/load-ttf";
import { render } from "@jimp/layout";

const font = await loadTTF("Inter-Bold.otf");

// A badge as big as its text
const badge = await render(
  {
    type: "box",
    direction: "row",
    radius: 6,
    overflow: "hidden",
    font,
    fontSize: 14,
    color: "white",
    children: [
      { type: "text", text: "build", padding: [4, 8], background: "#555555" },
      { type: "text", text: "passing", padding: [4, 8], background: "#22c76b" },
    ],
  },
  { Jimp },
);

await badge.write("badge.png");
```

### Get the positions without drawing

`layout` returns where every node goes, as boxes on the image in whole pixels, in the same tree shape. Text nodes also get the `text` that's drawn, after `maxLines`:

```ts title="example.ts"
import { layout } from "@jimp/layout";

const result = await layout(
  {
    type: "box",
    direction: "row",
    gap: 10,
    children: [
      { type: "box", width: 100 },
      { type: "box", grow: 1 },
    ],
  },
  { width: 400, height: 100 },
);

result.children[1]; // { x: 110, y: 0, width: 290, height: 100, node, children: [] }
```

### Place something absolutely

`position: "absolute"` takes a node out of the column, for a background image or a corner badge. Nodes are drawn in tree order, so a background image goes first:

```ts title="example.ts"
const card = await render(
  {
    type: "box",
    padding: 48,
    justify: "end",
    children: [
      {
        type: "image",
        src: photo,
        fit: "cover",
        position: "absolute",
        top: 0,
        right: 0,
        bottom: 0,
        left: 0,
      },
      { type: "text", text: "Over the photo", font, fontSize: 64, color: "white" },
    ],
  },
  { width: 1200, height: 630, Jimp },
);
```

### JSX

`Box`, `Text` and `Image` build nodes from props, and `@jimp/layout/jsx-runtime` lets you write them as JSX. See [Write it with JSX](/jimp/guides/og-images/#write-it-with-jsx).

## Notes

- **A subset of flexbox.** Rows and columns don't wrap onto more lines, and there's no `flex-basis`, `order`, `z-index` or `aspect-ratio`. Nodes are drawn in tree order, so later siblings are drawn over earlier ones, whether they're absolutely positioned or not. (CSS draws positioned nodes last.) Put a background image first.
- **Differences from CSS.** Boxes are columns unless you set `direction: "row"`, like React Native. Boxes and text can shrink to their padding and border, as if they had `min-width: 0`, so set `shrink: 0` or a `minWidth` to keep something's size. Images don't shrink unless you set `shrink`, much like CSS's automatic minimum size for images. Borders are the same width and color on every side.
- **Text** is measured with [`measureText`](/jimp/methods/measure-text/) and [`measureTextHeight`](/jimp/methods/measure-text-height/) and drawn with [`print`](/jimp/methods/print/), so it wraps exactly like `print`. A text node without a set width is as wide as its longest line, up to the space there is.
- **Whole pixels.** Positions are worked out with fractions, then each node's edges are rounded to whole pixels, so neighbors still touch and backgrounds stay crisp.
- **Shadows show through.** Like [`boxShadow`](/jimp/methods/box-shadow/), a shadow is drawn under the whole box, so it shows through a transparent or semi-transparent background, where CSS would hide it.
- **Validation.** The tree is checked before anything is drawn. Unknown props, like `justifyContent`, and invalid values throw a `ZodError` with the path to the node. Text without a font throws ``layout: text needs a font. Set `font` on the text or on a box around it.`` A `loadTTF` font without a `fontSize` throws too, and so does a `fontSize`, `color`, `lineHeight` or `letterSpacing` set on text with a bitmap font. An image node with a path, URL or buffer throws when the `Jimp` class has no `read`.
- **Fonts and images are loaded by you**, once, so rendering many cards doesn't read them again.
- **Added in 2.2.**

<Aside type="tip">
  `render` draws with the methods from `@jimp/plugin-draw`, `@jimp/plugin-print`,
  `@jimp/plugin-border` and the resize plugins directly, so it works with a
  custom Jimp that has none of them. Only `read`, for image nodes with a path,
  needs the formats you read.
</Aside>
