`contain` scales the image to the largest size that fits inside a `w` × `h` box, keeping its aspect ratio, and fills the space around it with the image's background color.
The result is always exactly `w` × `h` and nothing is cropped, like CSS `object-fit: contain`.

## Signature

```ts title="contain.d.ts"
image.contain(options: {
  w: number;
  h: number;
  align?: number | { x?: number; y?: number };
  mode?: ResizeStrategy;
  premultiplyAlpha?: boolean;
}): this
```

`contain` changes the image in place and returns it, so you can chain more calls after it.

## Options

| Option             | Type                                          | Default          | Description                                                                                                                                                                           |
| ------------------ | --------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `w`                | `number`                                      | required         | The output width in pixels.                                                                                                                                                           |
| `h`                | `number`                                      | required         | The output height in pixels.                                                                                                                                                          |
| `align`            | `number` or `{ x?, y? }`                      | centered         | Where to place the image in the box: `HorizontalAlign` and `VerticalAlign` flags, or `{ x, y }` fractions from `0` to `1`. See [Alignment](#alignment).                              |
| `mode`             | [`ResizeStrategy`](/jimp/concepts/constants/) | built-in resizer | The resampling algorithm. See [resize strategies](/jimp/methods/resize/#resize-strategies).                                                                                           |
| `premultiplyAlpha` | `boolean`                                     | `true`           | Treat alpha as opacity. Pass `false` when alpha holds other data, to keep the color of transparent pixels. See [Alpha that isn't opacity](/jimp/methods/resize/#alpha-that-isnt-opacity). |

## Example

```ts title="example.ts"
import { Jimp } from "jimp";

const image = await Jimp.read("photo.jpg");

// 800 x 600 is scaled to 300 x 225 and centered in a 300 x 300 square
image.contain({ w: 300, h: 300 });

await image.write("square.png");
```

### Choose the padding color

The padding uses `image.background`, which is transparent black (`0x00000000`) for images loaded with `Jimp.read`.
Set it before calling `contain` to pad with a color:

```ts title="example.ts"
image.background = 0xffffffff; // opaque white, as 0xRRGGBBAA
image.contain({ w: 300, h: 300 });

await image.write("square.jpg");
```

## Alignment

`align` places the scaled image inside the box.
Only the direction with padding matters. A wide image in a square box fills the width, so only the vertical value has an effect.

### With flags

Combine at most one [`HorizontalAlign`](/jimp/concepts/constants/) value and one [`VerticalAlign`](/jimp/concepts/constants/) value with `|`:

```ts title="example.ts"
import { Jimp, HorizontalAlign, VerticalAlign } from "jimp";

const image = await Jimp.read("logo.png");

// Pin the logo to the bottom-right corner of the box
image.contain({
  w: 400,
  h: 400,
  align: HorizontalAlign.RIGHT | VerticalAlign.BOTTOM,
});
```

| Value                    | Places the image        |
| ------------------------ | ----------------------- |
| `HorizontalAlign.LEFT`   | against the left edge   |
| `HorizontalAlign.CENTER` | in the middle (default) |
| `HorizontalAlign.RIGHT`  | against the right edge  |
| `VerticalAlign.TOP`      | against the top edge    |
| `VerticalAlign.MIDDLE`   | in the middle (default) |
| `VerticalAlign.BOTTOM`   | against the bottom edge |

A direction you leave out is centered, so `VerticalAlign.BOTTOM` is the same as `HorizontalAlign.CENTER | VerticalAlign.BOTTOM`.

### With fractions

Pass `{ x, y }` to place the image anywhere between the edges, like the percentages of CSS `object-position`.
`0` is against the left or top edge, `0.5` the middle and `1` the right or bottom edge:

```ts title="example.ts"
// Like CSS object-position: 20% 80%
image.contain({ w: 300, h: 300, align: { x: 0.2, y: 0.8 } });

// Against the bottom edge; x is left out, so it's centered
image.contain({ w: 300, h: 300, align: { y: 1 } });
```

A missing `x` or `y` is centered (`0.5`), and values outside `0` to `1` are clamped.

Switch `align with` to `{ x, y } fractions` to use sliders instead of flags, and turn off `set background` to see the default transparent padding.

## Notes

- **It enlarges too.** An image smaller than the box is scaled up until it touches two of its sides.
- **JPEG output.** JPEG has no transparency, so the default transparent padding is written as black. Set `image.background` to the color you want first.
- **Translucent pixels.** The scaled image is drawn over the padding color, so pixels that are partly transparent blend with `image.background`.
- **`premultiplyAlpha: false`** copies the scaled image into the box instead of drawing it over the background, so its alpha and the color of its transparent pixels are kept exactly.
- **Invalid flags.** Two flags for one direction (such as `VerticalAlign.TOP | VerticalAlign.BOTTOM`), unknown bits or a fractional number throw `align must combine at most one HorizontalAlign and one VerticalAlign flag`. `align: 0` has no flags, so it's centered.
- **Added in 2.0:** `{ x, y }` fractions for `align`, the `premultiplyAlpha` option, and the `LANCZOS`, `LANCZOS2` and `MITCHELL` strategies.
- **Changed in 2.0:** a direction left out of `align` is centered, and any invalid combination of flags throws. Before, a missing direction aligned to the left or top, and two flags in one direction were accepted unless both directions were invalid.

  crops the overflow instead. To fit without padding, use
  [`scaleToFit`](/jimp/methods/scale-to-fit/).
</Aside>
