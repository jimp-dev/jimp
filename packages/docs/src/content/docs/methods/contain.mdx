`contain` scales the image to the largest size that fits inside a `w` × `h` box, keeping its aspect ratio, and fills the space around it with the image's background color.
The result is always exactly `w` × `h` and nothing is cropped, like CSS `object-fit: contain`.

## Signature

```ts title="contain.d.ts"
image.contain(options: {
  w: number;
  h: number;
  align?: number;
  mode?: ResizeStrategy;
}): this
```

`contain` changes the image in place and returns it, so you can chain more calls after it.

## Options

| Option  | Type                                         | Default                                          | Description                                                                               |
| ------- | -------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| `w`     | `number`                                     | required                                         | The output width in pixels.                                                               |
| `h`     | `number`                                     | required                                         | The output height in pixels.                                                              |
| `align` | `number` | centered | Where to place the image in the box. Defaults to `HorizontalAlign.CENTER \| VerticalAlign.MIDDLE`. See [Alignment](#alignment). |
| `mode`  | [`ResizeStrategy`](/jimp/concepts/constants/) | built-in resizer                                 | The resampling algorithm. See [resize strategies](/jimp/methods/resize/#resize-strategies). |

## Example

```ts title="example.ts"
import { Jimp } from "jimp";

const image = await Jimp.read("photo.jpg");

// 800 x 600 is scaled to 300 x 225 and centered in a 300 x 300 square
image.contain({ w: 300, h: 300 });

await image.write("square.png");
```

### Choose the padding color

The padding uses `image.background`, which is transparent black (`0x00000000`) for images loaded with `Jimp.read`.
Set it before calling `contain` to pad with a color:

```ts title="example.ts"
image.background = 0xffffffff; // opaque white, as 0xRRGGBBAA
image.contain({ w: 300, h: 300 });

await image.write("square.jpg");
```

## Alignment

`align` places the scaled image inside the box.
Combine one [`HorizontalAlign`](/jimp/concepts/constants/) value and one [`VerticalAlign`](/jimp/concepts/constants/) value with `|`:

```ts title="example.ts"
import { Jimp, HorizontalAlign, VerticalAlign } from "jimp";

const image = await Jimp.read("logo.png");

// Pin the logo to the bottom-right corner of the box
image.contain({
  w: 400,
  h: 400,
  align: HorizontalAlign.RIGHT | VerticalAlign.BOTTOM,
});
```

| Value                    | Places the image          |
| ------------------------ | ------------------------- |
| `HorizontalAlign.LEFT`   | against the left edge     |
| `HorizontalAlign.CENTER` | in the middle (default)   |
| `HorizontalAlign.RIGHT`  | against the right edge    |
| `VerticalAlign.TOP`      | against the top edge      |
| `VerticalAlign.MIDDLE`   | in the middle (default)   |
| `VerticalAlign.BOTTOM`   | against the bottom edge   |

Only the direction with padding matters. A wide image in a square box fills the width, so only the vertical value has an effect.

## Notes

- **It enlarges too.** An image smaller than the box is scaled up until it touches two of its sides.
- **JPEG output.** JPEG has no transparency, so the default transparent padding is written as black. Set `image.background` to the color you want first.
- **`clone()` doesn't copy `background`.** A [clone](/jimp/methods/clone/) starts with a transparent background, so set it on the image you call `contain` on.
- **Include both directions in `align`.** A direction you leave out isn't centered: it aligns to the left or top. `align: VerticalAlign.BOTTOM` puts the image in the bottom-left corner.
- **Invalid alignment.** `align: 0`, or a value with more than one flag in both directions, throws `only use one flag per alignment direction`. The check only throws when both directions are invalid, so always pass exactly one flag from each enum.

<Aside type="tip" title="Fill the box instead">
  To fill the whole box with no padding, use [`cover`](/jimp/methods/cover/). It
  crops the overflow instead. To fit without padding, use
  [`scaleToFit`](/jimp/methods/scale-to-fit/).
</Aside>
