`clone` makes an independent copy of an image.
Image methods change the image they're called on, so clone first whenever you need the original as well as the edited version: several sizes from one upload, a before and after, or a patch to draw back on top.

## Signature

```ts title="clone.d.ts"
image.clone(): Jimp
```

`clone` is synchronous. It returns a new image and leaves the original unchanged.

## Example

```ts title="example.ts"
import { Jimp } from "jimp";

const image = await Jimp.read("photo.jpg");

const thumbnail = image.clone().resize({ w: 150 });
const preview = image.clone().resize({ w: 800 }).blur(2);

await thumbnail.write("thumb.jpg");
await preview.write("preview.jpg");
await image.write("original.jpg"); // still full size and sharp
```

### Edit part of an image

Clone, edit the copy, then draw it back onto the original:

```ts title="example.ts"
const area = { x: 40, y: 30, w: 120, h: 120 };

const patch = image.clone().crop(area).pixelate(10);

image.composite(patch, area.x, area.y);
```

### Why you need it

Methods return the same image they were called on, not a copy, so assigning the result doesn't keep the original:

```ts title="example.ts"
const small = image.resize({ w: 100 });

small === image; // true: `image` was resized too
```

See [Chaining and async](/jimp/concepts/chaining-and-async/) for more.

## Notes

- **What's copied.** The pixel data and size, the MIME type (`image.mime`), the [`background`](/jimp/concepts/reading-and-writing/#image-properties) color, the ICC color profile and the EXIF data. So `getBuffer("image/jpeg", { exif: true })` works on a clone of a JPEG too, and a clone of a Display P3 photo is still Display P3.
- **Cost.** Cloning copies every pixel: 4 bytes per pixel, so about 48 MB for a 12-megapixel photo. Clone once and reuse the copy rather than cloning in a loop. If you only need a smaller version, resize a clone once and work from that.
- **Same class.** A clone of an image from a [custom Jimp](/jimp/guides/custom-jimp/) has the same plugins and formats as the original.
- **Changed in 2.0:** `clone` copies `mime`, `background`, the EXIF data and the ICC profile. Before, the clone's `mime` was `undefined`, its background was reset to transparent and it had no EXIF data.

<Aside type="tip" title="Clone before the destructive step">
  You only need a copy of the state you want to keep. Do work that every
  version shares, such as a first crop or resize, before cloning so it isn't
  repeated.
</Aside>
