Load your fonts by URL with `loadFont` instead. ## With hosted file You can initialize a Jimp instance from a URL or a file path. ```ts import { Jimp } from "jimp"; // Read a file hosted on the same domain const image1 = await Jimp.read("/some/url"); // Read a file hosted on a different domain const image2 = await Jimp.read("https://some.other.domain/some/url"); ``` ## With uploaded files Or you can use Jimp with an `ArrayBuffer`. Here we take a user's uploaded image and modify it to greyscale. ```ts async function handleFile(file: File) { const image = await Jimp.fromBuffer(await file.arrayBuffer()); image.greyscale(); output.src = await image.getBase64("image/jpeg"); } ``` > !tip Try it > Use File > Open in JimPaint (or drop a picture on the canvas).
