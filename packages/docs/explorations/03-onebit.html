Welcome to Jimp

Jimp

The JavaScript Image Manipulation Program

Load an image, change it, save it. Jimp resizes, crops, filters and encodes images in the browser and Node.js, written entirely in JavaScript. Every picture on this page was drawn by Jimp, live, in two colours.

Read the docs Open JimPaint GitHub ↗
npm install jimp

Image formats

PNG, JPEG, BMP, GIF and TIFF out of the box. WEBP and AVIF through WASM plugins.

Manipulation

Resize, crop, rotate, blur, dither, mask, composite and a lot more.

Pluggable

Write plugins to add your own methods or image formats.

Just JavaScript

No native binaries. If it runs JavaScript, it runs Jimp.
