# @jimp/pngjs

A maintained fork of [pngjs](https://github.com/pngjs/pngjs).

## Based on pngjs

This package started as a copy of [pngjs](https://github.com/pngjs/pngjs) 7.0.0
(commit `c565210`), by Luke Page and the pngjs contributors, which was itself
based on [node-pngjs](https://github.com/niegowski/node-pngjs) by Kuba
Niegowski. Their copyright notices are kept in [LICENSE](./LICENSE).
