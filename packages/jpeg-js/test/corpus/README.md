# Conformance corpus

JPEGs decoded by `../conformance.node.test.ts` and compared with
libjpeg-turbo 3.2's djpeg. `references.json` has djpeg's output for each one,
as a SHA-256 of the samples and, for images up to 150,000 pixels and every
12-bit image, a PNG in `references/`. `generate.sh` regenerates `generated/`
and the references; it needs cjpeg, djpeg and ImageMagick, so CI only uses
its committed output.

| Folder           | Source                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generated/`     | Made by `generate.sh` with cjpeg and ImageMagick from `sources/testorig.ppm`: every chroma subsampling (4:4:4, 4:2:2, 4:2:0, 4:4:0, 4:1:1, 4:1:0, 3:1:1 and mixed), baseline and progressive, restart markers, greyscale, RGB, YCCK, 12-bit, 16-bit quantization tables, non-interleaved scans, sizes from 1x1 that don't fill whole MCUs, progressive JPEGs cut off after a scan, and arithmetic and lossless JPEGs that must be rejected. |
| `libjpeg-turbo/` | libjpeg-turbo's `testimages` (IJG license, see `../../README.ijg`), including its 12-bit and arithmetic-coded test images. `sources/testorig.ppm` is from there too.                                                                                                                                                                                                                                                                        |
| `jpeg-js/`       | jpeg-js's test fixtures (BSD 3-Clause): CMYK and YCCK, Adobe RGB, progressive, restart markers, fill bytes, trailing bytes, a lost 0xFF before an APP1 marker (`table-with-bad-e1.jpg`) and a 6000x6000 image.                                                                                                                                                                                                                              |
| `pdfjs/`         | pdf.js's `test/images/fish.jpg` and JPEGs extracted from the reduced test cases in pdf.js's `test/pdfs` (Apache 2.0): CMYK with subsampled K, greyscale with 2x2 sampling, DQT after SOF, restart markers and Adobe markers.                                                                                                                                                                                                                |
| `issues/`        | Images attached to jpeg-js issues: #17 (chroma upsampling), #77 (colour differences), #81 (a progressive JPEG cut off after 7 scans) and #109.                                                                                                                                                                                                                                                                                              |
